# Sophie Charlotte Masak — Personal Website

Personal academic website with a biography, searchable publications and manuscripts, research experience, education, skills, and a printable CV.

## Files

- `index.html` — main website, styling, and publication filtering
- `cv.html` — printable curriculum vitae; use the print button to save as PDF
- `portrait.jpg` — portrait supplied in the original CV

## Preview

Open `index.html` in a browser. No installation or build step is required.

For a local web server, run `python3 -m http.server 8000` from this directory and visit http://localhost:8000.

## Updating content

Edit `index.html` to update the biography, research history, and publications. Publication status filters read the `data-status` attribute on each publication. Update `cv.html` separately to keep the printable CV current.

Content is based on the September 2026 CV. Birth date, home location, and mobile number are omitted.

## Hosting

The files can be served by any static website host, including GitHub Pages. For GitHub Pages, select the `main` branch and the repository root in Settings → Pages after choosing the desired repository visibility and publishing settings.
